# Data Job dashboard project

This Power BI project analyzes a dataset of data-related job postings to explore hiring trends, job roles, locations, required skills, experience levels, and salary information. The interactive dashboard provides insights into the data job market, helping identify in-demand skills, popular roles, and employment opportunities across different locations and categories.
## Dashboard Features
The dashboard features multiple interactive pages designed for easy navigation and data exploration. 
It includes interactive buttons, slicers, Cards, charts, tables, drillthrough and other visualizations.
Users can filter and explore job posting data dynamically, while the interactive elements provide a clear and engaging way to navigate between different sections of the dashboard.

## The dashboard has four pages 👇

1. Data Job Dashboard HomePage
2. Job Drillthrough Page

### Data Job Dashboard

**Home Page:**

This page provides an interactive overview of the data job market, featuring key metrics such as total job count, average job rating, and median yearly and hourly salaries. It includes job posting trends, salary comparisons by job title, job counts across roles, and a detailed job-title table. A job-title slicer also allows users to filter the dashboard and explore specific roles.

![Data Job Dashboard Image](/Data%20Job%20Dashboard.png)

### Job Drillthrough

**Job Drillthrough Page:**

This page provides a detailed overview of a selected data-related job role, with the current selection shown as **Business Analyst**. It presents salary insights through yearly and hourly salary gauges, alongside visualizations of work-from-home availability, health insurance, and degree requirements. Additional charts show job schedule types, popular job platforms, and the geographical distribution of job postings by country.
![Job Drillthrough Image](/Job%20Drillthrough.png)

### Tools & Skills
**Power BI** — Dashboard development and interactive visualizations

**Power Query** — Data cleaning and transformation

**DAX** — Measures and calculated metrics

**Data Visualization** — Charts, cards, tables, slicers, and interactive navigation

**Data Analysis** — Salary, job type, location, and posting-trend analysis

### Project Outcome
This project demonstrates the use of Power BI to transform raw job posting data into an interactive dashboard that makes salary patterns, job characteristics, geographical distribution, and posting trends easier to explore and understand.
